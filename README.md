# About

**Re4QuadNewAge-Modded** is a heavily modified and modernized version of [**Re4QuadNewAge**](https://github.com/JADERLINK/Re4QuadNewAge).

The project expands the original editor with a modern interface, improved editing workflow, additional file formats, project management, camera tools, object manipulation, Gizmo controls, rendering options, templates, libraries, and many quality-of-life improvements.

The main goal is simple:

> **Make Resident Evil 4 modding faster, easier, and more enjoyable.**

Instead of relying on multiple separate utilities for common editing tasks, Re4QuadNewAge-Modded aims to bring more of the workflow into a single editor.

# 📐 Snap System

The editor includes precision snapping for accurate object placement.

| Key | Snap Value |
| :-: | ---------: |
| `1` |      `1.0` |
| `2` |      `0.1` |
| `3` |     `0.01` |
| `0` |        Off |

Both the normal number row and numeric keypad can be used.

# 🎥 Camera System

Camera manipulation has been expanded to make scene editing much easier.

### Camera Features

* Camera View
* Camera navigation
* FOV controls
* Camera reset
* Precision movement
* Object → Camera positioning
* Camera → Object positioning

### Camera View

Select a camera object and press:

`E`

to enter Camera View.

Press:

`Esc`

to leave Camera View.

# 🐌 Precision Movement

Holding `Alt` while using movement keys enables slower movement for more precise positioning.

|    Shortcut   | Action        |
| :-----------: | ------------- |
|   `Alt + W`   | Move Forward  |
|   `Alt + A`   | Move Left     |
|   `Alt + S`   | Move Backward |
|   `Alt + D`   | Move Right    |
| `Alt + Space` | Move Up       |
|   `Alt + C`   | Move Down     |

This is especially useful when positioning objects or cameras precisely.

# ⚠️ Known Issues

The project is actively developed and may contain bugs or version-specific limitations.

### Theme Switching

There is currently a known issue when switching between **Dark Mode** and **Light Mode** where some interface elements may not update correctly.

If this occurs, restart the application to reload the selected theme correctly.

Other issues may depend on:

* Game version
* File type
* Unsupported or unusual game data
* Custom mod files

If you encounter a problem, please open an issue and include as much information as possible.
